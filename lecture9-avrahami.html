מה מכינים מראש

ההרצאה הבאה היא סדנה שבה כל משתתף עובד על המחשב שלו. ההכנה היא תנאי להשתתפות מלאה.

▶

הנחיות להכנה לקראת הרצאה 10

מתוך הקובץ ״הנחיות לביצוע לפני השיעור הבא״ של ד״ר פאול אברהמי · ההדגמה ב-Windows
המטרה: שיהיה לכם על המחשב סביבת עבודה מוכנה (Git, עורך קוד, Claude ופרויקט לדוגמה), כך שאפשר יהיה להתחיל לעבוד יחד מרגע פתיחת ההרצאה.
  1. מתקינים Git. כלי לניהול גרסאות של קוד. git-scm.com/install/windows
  2. מתקינים Visual Studio Code. עורך הקוד שבו נעבוד. code.visualstudio.com/download
  3. מתקינים את Claude ופותחים חשבון. עדיף חשבון Pro. claude.com/download
  4. פותחים תיקייה ייעודית בתיקיית המשתמש שלכם (בדוגמה: C:\Users\<שם המשתמש>\claude), ב-PowerShell או בשורת הפקודה:
    >mkdir claude
  5. נכנסים לתיקייה ומשכפלים את פרויקט הדוגמה (מעקב הוצאות בסיסי):
    >cd claude
    >git clone https://github.com/mosh-hamedani/expense-tracker-starter.git
  6. נכנסים לתיקיית הפרויקט ופותחים אותה בעורך:
    >cd expense-tracker-starter
    >code .
    הפקודה פותחת את Visual Studio Code על הפרויקט. משם נמשיך בהרצאה.
